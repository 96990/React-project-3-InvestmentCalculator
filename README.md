#about
A React-based web application designed to calculate the future value of investments over a specified period of time. Users can input key parameters such as:

    Initial Investment: The starting amount of money invested.
    Duration: The time period (in years, months, or days) for the investment.
    Expected Return Rate: The annual or periodic rate of return on the investment.
    
The application dynamically computes and displays the projected growth of the investment, providing a clear breakdown of the total value over time. This tool is ideal for individuals looking to plan and visualize their financial goals.
